# 源码兼容补丁

本目录把原本只存在于本机 02、03 源码中的 mask 接口单独分发，避免另一台电脑下载官方仓库后不认识配置里的 `--masks` 参数。

- `02_2DGS_masks.patch`：基于 `hbb1/2d-gaussian-splatting@f3e3b9fa67bbd1c75e05167ff37391d8dab2a678`，传递 mask 路径、加载 COLMAP 相机对应的 `<image_name>.mask.png`，并沿用本机 mask 区域处理方式。
- `03_Gaussian_Surfels_masks.patch`：基于 `turandai/gaussian_surfels@01d12493a8be16a8a9f69e76ffe633093f23ebef`，提供显式 mask 目录参数，接入上游已有的 mask 读取接口。

补全脚本负责应用补丁，已应用的补丁会跳过；冲突会报错，绝不强制覆盖本地修改。补丁不包含本机额外的逐轮指标记录代码。源码及其使用条件仍以各上游仓库附带的许可证为准。

## 训练协议的已知问题

这些补丁用于同步原有本机接口，不等于已经完成训练协议审查。本次源码补全未修改以下既有行为，正式对比结果前需要单独处理：

- 03 的上游 mask 读取器把灰度值除以 255；当前数据中抽查到的前景灰度为 70，会被当成约 0.275 的透明度，而不是二值有效区域。
- 03 当前测试命令未传 `--img`，上游渲染器不会保存供统一指标计算使用的 RGB 图像；这不影响 `--mode train` 启动，但会影响后续测试。
- 02 沿用本机“用预测值替换 mask 区域的监督图像”方式，完整图像的 SSIM 窗口仍可能对 mask 区域产生梯度，不能声称严格排除了所有 mask 区域梯度。
